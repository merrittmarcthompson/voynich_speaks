# Voynich Speaks — Phonetic Transcription

Companion files for the Medium article **Voynich Speaks**, exploring a phonetic transcription of the Voynich Manuscript.

## Files
* **`RF1a-n.txt`** — A copy of the original IVTFF EVA transliteration source file.
* **`RF1a-n_analyzer.py`** — My Python script mapping EVA characters to phonetic values.
* **`RF1a-n_translation.txt`** — Analyzer program output. This file is the same as the original EVA-format RF1a-n.txt file but with phonetic transliterations interleaved. Transliterations are in CAPS to distinguish them from EVA for easy searching.
